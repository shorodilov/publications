# Support

This repository is maintained on a best-effort basis.

## What this repository supports

Use repository issues or discussions for questions related to:

- Repository structure.
- Publication materials stored in this repository.
- Metadata schema behavior.
- Validation examples.
- Build, conversion, or documentation workflow problems.
- Contribution process questions.

## Before asking for help

Please check:

1. The README.
2. Existing issues and pull requests.
3. Relevant documentation in the repository.
4. Existing examples close to the file or workflow you are using.

## How to ask a useful question

When opening an issue, include:

- What you are trying to do.
- Which file, schema, article, or command is involved.
- What you expected to happen.
- What actually happened.
- A minimal example or reproduction case, if possible.

For schema or build problems, include the smallest input that reproduces
the issue.

## What is not supported

This repository does not provide:

- General technical support unrelated to the repository.
- Private consulting through issues.
- Support for unrelated publication pipelines.
- Emergency support or guaranteed response times.

## Security reports

Do not use public support channels for sensitive security reports.

See `SECURITY.md` for security reporting instructions.
